## 🚀 Selected projects

### 🧠 [Adaptive AI Tutor](https://github.com/onoizu/AI_Tutor)

A learning workspace for computer science and AI, combining guided explanations, quizzes, feedback, document-based Q&A, and editable study notes. The application connects a Next.js interface to an agent workflow with session context and structured learning responses.

`Next.js` `TypeScript` `Coze` `Document Augmentation`  
[Explore the code →](https://github.com/onoizu/AI_Tutor)

### 📰 [News Headline Clustering](https://github.com/onoizu/News-Headline-Clustering)

**Course group project · Unsupervised NLP**  
Explored topic discovery on **50,000 news headlines**, comparing text representations and using **Sentence-BERT → UMAP → HDBSCAN**. My contributions included deduplication, year-stratified sampling, text cleaning, EDA, and representation experiments. The repository also includes a refactored CLI and a synthetic demo.

`Python` `Sentence-BERT` `UMAP` `HDBSCAN`  
[Explore the code →](https://github.com/onoizu/News-Headline-Clustering)

### 📊 [IBM Telco Customer Retention](https://github.com/onoizu/IBMTelecom-Customer-Retention)

**Course group project · Customer analytics**  
Examines **7,043 customer records** through data auditing, exploratory analysis, and interpretable decision-tree modelling. Connects churn patterns with customer groups that warrant further retention investigation, with explicit evaluation and stability checks.

`Python` `pandas` `scikit-learn` `Decision Trees`  
[Explore the code →](https://github.com/onoizu/IBMTelecom-Customer-Retention)

### 🐾 [MeowHome](https://github.com/onoizu/MeowHome)

**Course project · Frontend development**  
A responsive cat-adoption and care website prototype with search and filters, a preference-matching questionnaire, adoption-flow demos, and English / Traditional Chinese switching. Built with vanilla web technologies and browser-local storage.

`HTML` `CSS` `JavaScript` `Responsive UI`  
[Explore the code →](https://github.com/onoizu/MeowHome)
